# Funds (JavaScript SDK)

The JavaScript SDK from Market Data provides methods designed to streamline your use of the following Funds endpoints. These intuitive methods provide a seamless interface for accessing mutual fund data.

## Funds Endpoints

- [Fund Candles (JavaScript SDK)](./candles.md) — Fetch daily OHLC candles for a mutual fund with the JavaScript SDK candles() method on the funds resource, as decoded records, raw JSON or a CSV Blob.
